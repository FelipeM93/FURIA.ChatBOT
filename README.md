# 🤖 FURIA.ChatBOT – Telegram Bot

Um bot de Telegram desenvolvido para fornecer atualizações em tempo real de partidas ao vivo de Counter-Strike: Global Offensive, assim como noticias e informações sobre o time e a marca FURIA

## 📌 Funcionalidades

- Consulta automática de partidas de CS:GO em andamento.
- Respostas interativas pelo Telegram.
- Interface com teclado customizado para facilitar o uso.
- Utilização da API PandaScore para dados ao vivo confiáveis.
- Simulação de Torcida

## 🚀 Tecnologias Utilizadas

- [Python](https://www.python.org/)
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot)
- [PandaScore API](https://developers.pandascore.co/)

## 🛠 Como rodar o projeto

### Pré-requisitos

- Python 3.10+
- Conta na [PandaScore](https://pandascore.co/) com chave de API
- Token de bot no [BotFather](https://t.me/botfather) do Telegram
